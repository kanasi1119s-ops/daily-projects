# フリーランス取引条件 明示書メーカー

フリーランス・事業者間取引適正化等法(2024年11月施行)で発注側に求められる取引条件の明示書を、フォーム入力から生成する静的Webツールです。
入力内容はブラウザ内のみで処理されます(外部送信なし)。

## 起動
ビルド不要。`index.html` をブラウザで開くだけです。

## テスト
- ロジック: `node --test test/*.test.js` (依存なし, Node 18+)
- UIスモーク(任意): `node test/ui.test.js` (playwright が必要)

## 機能
必須項目チェック / 支払期日の60日ルール警告 / 税込・税抜計算 / 検査日・非現金支払の条件付き必須 / コピー・印刷(PDF保存)

## 既知の制約
- 法的助言ではない。条文の解釈・最新要件は公式情報で確認が必要
- 60日ルールは「納期=受領日」とみなして判定(検査日は起算点にならない)
- 下請法等、他法令の記載事項は未対応
