# 法務レビュー: InvoiceLite（2026-09-23 MVP）

Legal-Reviewerフェーズのチェック結果。

- [x] **第三者コンテンツの権利処理** — 第三者の画像・文章・データは一切使用していない（アイコン・ロゴ等もなし、テキストとCSSのみで構成）。問題なし。
- [x] **スクレイピングの有無** — 外部サイトへのアクセス・データ取得は行っていない（完全にクライアントサイド完結）。対象外。
- [x] **個人情報の取り扱い** — 入力される氏名・住所・取引先名等はすべて `localStorage`（端末内）にのみ保存され、サーバー送信・外部送信は一切行わない。取得目的も保管方法も「本人の下書き保存」のみで最小限。★ただし複数端末利用や共有PCでは前の利用者の入力が残る可能性があるため、README・LP双方に「共有端末では新規作成ボタンで消去してから利用」を明記済み。
- [ ] **プライバシーポリシー** — 現時点で専用ページ未作成。公開前に人間が最終確認の上、簡易プライバシーポリシー（「入力データを送信しない」旨を明記するだけの短いもの）を追加することを推奨。★要人間対応
- [ ] **特定商取引法に基づく表記** — 現MVPは無料ツールであり、物販・有償役務の提供を行っていないため現時点では不要。将来的に有料プラン（サブスク等）を追加する場合は、特商法表記（事業者名・所在地・連絡先・返金条件等）の追加が必須。★要人間対応（有料化時）
- [x] **誇大な収益保証・効果保証の表現** — LP・SNS文言に「必ず」「絶対」「保証」等の断定的効果表現は含めていない（Sales-Writerフェーズでセルフチェック済み）。
- [x] **インボイス制度に関する表示の正確性** — 登録番号欄・税率区分（10%/8%/非課税）は制度上の一般的な記載様式に沿っており、法的助言や税務判断を行うものではない旨、README/LPに明記が望ましい。★LP文言に一文追加済み（「本ツールは書式作成の補助であり、税務・法務上の助言を行うものではありません」）

## 総合判定

法的リスクは低い。ブロッカーとなる項目はなし。ただし公開前に人間が以下を最終確認すること：
1. 簡易プライバシーポリシーページの追加
2. 将来的な有料化時の特定商取引法表記の追加
