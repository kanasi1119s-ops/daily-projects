# InvoiceLite

登録不要・サーバー保存なしで使える、見積書・請求書ジェネレーター（インボイス制度対応）。

## コンセプト

フリーランス・小規模事業者向けに、アカウント登録やクラウド保存を一切せず、ブラウザだけで完結する見積書・請求書作成ツール。入力データは端末の `localStorage` にのみ保存され、外部サーバーには一切送信されません。

- インボイス制度の登録番号欄に対応
- 品目ごとに税率（10% / 8% / 非課税）を指定可能
- 見積書 / 請求書を切り替えて発行
- ブラウザの印刷機能でそのままPDF保存

## 使い方（ローカルで動かす）

ビルド不要の静的サイトです。以下のいずれかの方法で起動できます。

```bash
# Python がある場合
cd 2026-09-23-invoice-generator
python3 -m http.server 8000
# http://localhost:8000 を開く
```

または `index.html` をブラウザで直接開いても動作します。

## 既知の制約（MVP時点）

- ロゴ画像のアップロードには未対応
- 複数テンプレート（デザインバリエーション）は未実装
- 過去に作成した書類の一覧管理・複数保存には未対応（直近の1件のみ下書き保存）
- PDF出力はブラウザの印刷機能（`window.print()`）に依存しており、ブラウザによって余白の見え方が多少異なる場合がある

## 収益化仮説（要検証）

- 無料版：基本テンプレート1種、単一下書き保存
- 有料版（仮）：複数テンプレート、ロゴアップロード、書類履歴の複数保存、PDF直接生成（ライブラリ組み込み）
- 決済導入（Stripe等）は人間の承認・本番接続が必要なため未実装
