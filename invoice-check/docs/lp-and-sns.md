# LP草稿
**キャッチコピー案**: 「T番号と消費税の端数、請求書を出す前の1分チェック。」 / 「入力はブラウザの外に出ません。」

**見出し**: インボイスチェッカー — 請求書まわりの“うっかり”を減らす無料ツール
**機能**
- 登録番号の形式チェック（法人番号はチェックデジットまで確認）
- 10%・8%の消費税を、税率ごとに1回の端数処理で計算
- 経過措置（80%→50%）の控除目安
- 適格請求書の記載事項チェックリスト
**安心**: サーバー送信なし・登録不要。
**料金プラン案(仮説)**: 無料（基本機能）／将来案: 請求書明細の保存・CSV出力などを月額少額で提供することを検証（要需要確認）
**注意書き**: 本ツールは参考情報です。登録の有無は国税庁公表サイトで、税務判断は税理士等にご確認ください。

# SNS告知文（草稿）

2. 「税率ごとに1請求書1回の端数処理」、地味に間違えがち。10%/8%混在でも一発計算できます。※参考用・税務判断は専門家へ
3. 2026年10月から仕入税額控除の経過措置は80%→50%に。控除の目安をその場で計算できます（要件は国税庁で確認を）。
