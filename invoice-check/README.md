# インボイスチェッカー (invoice-check)

登録番号(T番号)の形式確認・税率ごとの消費税端数計算・仕入税額控除の経過措置・適格請求書の記載事項チェックリストを、**ブラウザ内だけで**提供する静的Webツール。サーバー・DB・外部APIなし。入力データは送信/保存されません。

## 起動
```
npm install
npm run dev      # 開発
npm test         # ユニットテスト(vitest)
npm run build    # dist/ に静的ファイル出力
```

## 機能
1. T番号形式チェック（全角/ハイフン正規化、法人番号のチェックデジット検証）
2. 消費税計算（10%/8%、税抜/税込、切捨/四捨五入/切上、税率ごとに1請求書1回の端数処理、値引き=負数対応）
3. 経過措置控除の目安（〜2026/9: 80%, 2026/10〜2029/9: 50%）
4. 適格請求書の必須記載事項チェックリスト

## 制約・未実装
- 「登録済み」の確認は不可（国税庁公表サイトへのリンクのみ。公表サイトAPI連携は利用規約確認の上で次サイクル候補）
- 個人事業主のT番号はチェックデジットが無く形式のみ
- 2割特例・簡易課税・明細の保存/CSV出力は未実装
- 税制は改正され得るため、税率・経過措置は要定期確認
