# 取適チェッカー (torite-checker)

中小受託取引適正化法（取適法・旧下請法、2026年1月施行）の **対象判定の目安／支払期日（受領日から60日）／発注側の禁止行為** をブラウザだけでセルフチェックできる静的Webツール。入力内容は送信・保存されません（外部通信なし）。

## 機能（MVP）
1. 対象判定: 取引類型 × 資本金基準・従業員基準で「対象になる可能性」を表示（フリーランス法への注意喚起つき）
2. 支払期日: 受領日→60日目の算出、支払予定日の判定、締め日/支払サイトの最悪ケース日数（例: 20日締め翌月20日払いは最大62日）
3. 禁止行為セルフチェック: 協議拒否・手形払等・振込手数料負担など13項目

## 起動
```bash
npm install
npm run dev        # 開発サーバ
npm test           # ロジックの単体テスト(17件)
npm run build      # 型チェック + 本番ビルド → dist/
npm run preview -- --port 4173
NODE_PATH=$(npm root -g) node tests/e2e.cjs   # Playwright スモークテスト(要 preview 起動)
```

## 構成
- `src/lib/` 判定ロジック（applicability / payment / checklist）— UIから独立しテスト済み
- `src/components/` 各タブUI
- `docs/` 公開手順書・法務チェック・既知の課題・LP/SNS草稿

## 免責
法的助言ではありません。数値基準・禁止行為は公開情報に基づく簡易整理です。公開前に公正取引委員会・中小企業庁の一次情報で必ず再確認してください（docs/LEGAL_REVIEW.md 参照）。
