# マーケ素材（草稿）
## LP
**見出し**: 発注書の「書き忘れ」を、30秒で見つける。
**サブ**: フリーランスに仕事を頼むときの取引条件、記載漏れがないか確認できる無料ツール。
**機能**: 必須項目の抜け漏れチェック／日付の整合性チェック／支払期日が納期から60日を超える場合の警告／発注書テキスト生成／入力内容は送信されません（ブラウザ内で完結）
**料金案（仮説・要検証）**: 無料版=基本チェック。将来案=テンプレ保存・PDF出力の有料版（未実装）
**注意書き**: 本ツールは法的助言ではありません。最終確認は公式資料または専門家で。
## SNS案
1. 「フリーランスへの発注書、取引条件の記載漏れはありませんか？ 項目チェックと雛形生成ができる無料ツールを作りました。入力はブラウザ内だけで処理されます。※法的助言ではありません」
2. 「納期・報酬額・支払期日…書き忘れやすい項目をまとめて確認。支払期日が納期から60日超だと警告します（要・公式資料確認）」
3. 「発注側の“うっかり”を減らす小さなツール。まずは使ってみて、ご意見ください」
