# 取引条件明示チェッカー

フリーランスへ業務委託する発注者向けに、書面等へ記載すべきとされる主な取引条件の抜け漏れを確認し、発注書の雛形テキストを生成する静的Webツール。入力はブラウザ内のみで処理（送信・保存なし）。法的助言ではありません。

## 起動
```
npm start     # http://localhost:8080 （ES Modulesのため file:// では動かない）
npm test      # ロジックのユニットテスト（Node 20+）
```
## 構成
- `index.html` UI / `src/checker.js` 判定ロジック / `src/app.js` DOM連携 / `test/` テスト / `docs/` 公開手順・法務・マーケ素材

## チェック項目
発注者名・受注者名・委託日・業務内容・納期・納品場所・検査完了日(任意)・報酬額(税区分)・支払期日・現金以外の支払方法(任意)。日付整合性と「納期から60日超の支払期日」を警告。
※項目・60日基準は一般的な整理。公式資料(公正取引委員会・厚生労働省)での確認が必要（docs/legal.md）。

## MVPに含まない
PDF出力、取適法の適用判定、契約書レビュー、保存機能、多言語。
