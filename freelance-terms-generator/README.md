# 取引条件明示ジェネレーター

フリーランス新法(特定受託事業者に係る取引の適正化等に関する法律)第3条の取引条件明示事項を、フォーム入力から整形して文書化する静的Webツール。サーバー送信なし・ブラウザ内完結。

## 起動
```
npm test        # ロジックの単体テスト(Node 18+、依存なし)
npm start       # http://localhost:8080
npm run build   # dist/ に静的ファイルを出力
```

## 構成
- `src/terms.js` 検証・60日ルール計算・文書生成(DOM非依存)
- `src/app.js` UI
- `test/` 単体テスト / `e2e/` ブラウザ試験
- `docs/` 法務チェック・QA・公開手順・LP/SNS草稿・日次レポート

## MVPスコープ
含む: 必須項目検証、支払期日60日上限チェック、コピー、印刷/PDF。
含まない: アカウント、保存、決済、テンプレート複数種、再委託の例外判定。

法的助言ではありません。公開前に `docs/LEGAL.md` の要対応事項を確認してください。
