# サブスクキーパー (sub-keeper)

契約中のサブスクを**年額で見える化**し、**支払い日前にカレンダー通知**できる、ブラウザ完結の静的Webアプリ。
アカウント不要・サーバー不要。データは `localStorage` のみに保存し、外部送信しません（CSPで通信を遮断）。

## 機能
- サブスクの追加/編集/削除/停止中フラグ（週・月・3か月・半年・年の周期）
- 月額・年額合計、カテゴリ別内訳、30日以内の支払い一覧
- `.ics` 書き出し（次回支払日の3日前に通知）
- CSV書き出し/読み込み（CSVインジェクション対策済み）

## 起動
```
npm start        # http://localhost:8080
npm test         # ロジックのユニットテスト（Node 22）
```
ビルド不要。`index.html` + `src/` を任意の静的ホスティングに置けば公開可能（`docs/PUBLISH.md` 参照）。

## 既知の制約
- 通貨は円のみ、為替・税・日割りは非対応
- 端末間同期なし（CSVで手動移行）
- CSV読み込みは重複チェックなし（追記される）
- 銀行/カード明細からの自動検出は未実装（次サイクル候補）
