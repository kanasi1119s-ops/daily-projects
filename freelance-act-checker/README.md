# フリーランス新法 取引条件チェッカー

発注側・受注側どちらでも使える、フリーランス・事業者間取引適正化等法（2024-11-01施行）の**セルフチェック用**静的Webツール。外部送信なし、ブラウザ内完結。

## 機能（MVP）
1. 第3条 取引条件の明示事項の過不足チェック＋通知書ひな形テキスト生成
2. 第4条 支払サイト検証：「末日締め翌々月10日払い」等のルールを、受領日の全日・12か月で検証（60日／2か月以内運用）
3. 第5条 禁止行為セルフチェック

含まない: 契約書レビューAI、電子署名、アカウント/保存機能、再委託の例外判定（30日ルール）、第16条中途解除予告等の判定。

## 起動
```
npm start     # http://localhost:8080
npm test      # コアロジックのテスト
```
## 構成
`src/core.js` ロジック（依存なし）／`src/app.js` UI／`test/` テスト／`docs/` 法務・公開手順・LP・SNS

## 免責
法的助言ではありません。公正取引委員会・厚生労働省の公式資料で最終確認してください。
