## デバッグ3サイクルの記録
| 回 | 検出した問題 | 対応 |
|---|---|---|
| 1 | 開発用サーバー: 存在しないパスで `ERR_HTTP_HEADERS_SENT` によりプロセスがクラッシュ / パス判定が前方一致でディレクトリ外へ抜けうる / JSON復元を繰り返すと重複登録 | 読込→送信の順に修正、`sep`付き判定に変更、重複判定を追加 |
| 2 | localStorage内のデータに id が無い/重複する場合、1件の削除・編集が複数行に波及 | 読込時に id を再採番(`uniqueIds`) |
| 2→3 | 上記修正で `newId` が初期化前参照(TDZ)となりデータが空扱いに(修正の副作用) | 関数宣言に変更し再テストで確認 |
| 3 | ICSを外部パーサーで検証 → 問題なし | 追加修正なし |
