# 法務レビュー チェックリスト（Legal-Reviewer フェーズ）

対象プロジェクト: 有給休暇 連休最大化プランナー (paid-leave-planner-2026)
レビュー日: 2026-09-27

## チェック結果

- [x] **第三者コンテンツの権利処理**
  祝日の名称・日付は事実（内閣府が公表する制度情報）であり、著作物性・第三者の権利は発生しない。
  文章・デザイン・コードはすべて本サイクルで新規作成したオリジナル。第三者の画像・氏名・SNSアカウントは一切使用していない。

- [x] **スクレイピングの利用規約・robots.txt確認**
  本アプリはスクレイピングを行わない（祝日データはビルド時に静的ファイルへ手入力しており、実行時に外部サイトへアクセスしない）。
  データ収集時（本サイクルのリサーチ）はWeb検索結果の要約情報を参照し、複数の情報源で数値を突合したのみで、
  特定サイトの本文をそのまま複製していない。

- [x] **個人情報の取得・保管**
  本アプリはユーザー入力（残り有給日数など）をサーバーに送信せず、ブラウザ内のJavaScriptのみで完結する。
  個人情報の取得・保存は一切行っていない（Cookie・localStorageの利用もなし）。

- [★要人間確認] **特定商取引法に基づく表記**
  現時点では物販・有料役務の提供を行っていないため対象外。
  将来、有料プラン（サブスクリプション等）を導入する場合は、特定商取引法に基づく表記（事業者名・所在地・連絡先等）の
  整備が必要。**事業者情報の記入は人間が行うこと。**

- [x] **誇大な効果・収益保証表現の有無**
  LP・SNS告知文において「必ず得する」「絶対に」等の断定的な保証表現は使用していない。
  「最大〇日」「効率よく」等、計算ロジックに基づく相対的な訴求のみに留めている（Sales-Writerフェーズでセルフチェック済み）。

## 総合判定

**次フェーズ（デプロイ準備）に進行可。** 未確認・要対応事項は「特定商取引法」項目のみで、
これは有料化を検討する段階になってから人間が対応すべき事項として日次レポートに記載する。

- 祝日データは制度改正（祝日法改正等）により変更されうるため、年次更新時に内閣府公式発表との突合を行うこと
- 将来、ユーザーアカウント機能や勤怠システム連携を追加する場合は、個人情報保護法・プライバシーポリシーの整備を
  公開前に必ず人間が確認すること
