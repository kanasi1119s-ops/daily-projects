## 公開手順（人間が実行）

### 選択肢A: GitHub Pages（無料・最短）

1. リポジトリの Settings → Pages で、公開元ブランチとして本ブランチの
   `projects/paid-leave-planner-2026` ディレクトリを指定（もしくはこのディレクトリの内容を
   `gh-pages` ブランチのルートにコピー）
2. 公開URLが発行されたらブラウザで動作確認

### 選択肢B: Vercel / Netlify / Render Static Site

1. 対象ディレクトリ: `projects/paid-leave-planner-2026`
2. ビルドコマンド: なし（空欄）
3. 公開ディレクトリ（Publish/Output Directory）: `.`（このディレクトリ自体）
4. デプロイ実行 → 発行されたURLで動作確認
