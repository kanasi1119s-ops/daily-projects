# インボイス特例 比較シミュレーター

2割特例終了後の **3割特例（個人・令和9/10年分）／簡易課税／本則課税** の消費税納付額を比較する、ブラウザ完結の静的ツールです。入力値は外部送信・保存されません。

## 起動手順
```bash
npm test          # ロジックの単体テスト（Node 20+）
npm run build     # dist/ に静的ファイルを出力
npm start         # http://localhost:8080 で dist/ を配信
```
依存パッケージなし。E2E（任意）: `NODE_PATH=$(npm root -g) npm run e2e`（Playwright必要）

## 構成
- `src/calc.js` 計算ロジック（純粋関数） / `src/app.js` UI / `index.html` `style.css`
- `test/` 単体・E2E / `docs/` 法務チェック・公開手順・LP・SNS文面

## MVPスコープ
含む: 標準税率10%、本則・簡易・2割・3割の比較、適用要件の簡易判定、免税事業者に戻る選択肢の注意喚起
含まない: 軽減税率8%、個別対応/一括比例配分、複数事業区分の按分、特例の細かな適用除外、100円未満切捨て

## 免責
税務上の助言ではありません。3割特例の要件は税制改正に基づく解説記事ベースの実装で、国税庁一次資料での確認が**公開前に必須**です。
