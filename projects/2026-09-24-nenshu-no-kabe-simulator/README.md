# 年収の壁 かんたんシミュレーター

2026年10月の制度改正（106万円の壁の賃金要件撤廃、130万円の壁の要件変更など）に対応した、
パート・アルバイトで働く方向けの「年収の壁」目安チェックツールです。

- **完全クライアントサイド**: 入力データはブラウザ内でのみ計算され、サーバーへの送信・保存は一切ありません。
- **最新の制度改正に対応**: 2025〜2026年の税制・社会保険制度改正を反映した目安ラインを表示します。
- **バックエンド不要**: 静的サイトとしてどこにでもデプロイ可能です。

## コンセプト

- **ターゲットユーザー**: 年収の壁を意識しながら働くパート・アルバイト従業員、扶養する家族（配偶者・親）
- **収益化仮説（検証段階・未実装）**: 表示広告（Google AdSenseなど）、または詳細レポートPDFの有料ダウンロード
- **MVPスコープに含む**: 主要な壁（123万・130万・169万・178万・106万＝条件付き）の判定、学生控除の考慮、勤務先規模による106万円の壁の表示切り替え
- **MVPスコープに含まない**: ログイン・データ保存機能、実際の決済、外部APIとの連携、個別の税務相談機能

## 起動手順

```bash
npm install
npm run dev       # 開発サーバー起動
npm run test      # ユニットテスト実行
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果をローカルでプレビュー
```

## 免責事項

本ツールは公開情報をもとにした概算シミュレーションであり、正式な税務・社会保険の判定を行うものではありません。
実際の適用は個々の状況により異なるため、最終判断は専門家にご確認ください。
