# ゼイクラベ（zeikurabe）

インボイス制度後の消費税納税額を **本則課税 / 簡易課税 / 2割特例** で並べて比較する、依存ゼロの静的シミュレーター。入力はブラウザ内で計算され、送信・保存しません。

## 起動
```
npm start        # http://localhost:5173
npm test         # 単体テスト(node:test)
```
ビルド不要の静的サイトです（`index.html` / `style.css` / `src/*.js`）。

## 構成
- `src/tax.js` 計算ロジック（整数演算ベース、100円未満切捨て）
- `src/parse.js` 金額入力のパース
- `src/app.js` UI
- `test/` 単体テスト
- `docs/` 法務チェック・公開手順書・QA記録・LP/SNS草稿

## 前提と制約（MVP）
標準税率10%のみ。軽減税率・売上返還・貸倒れ・課税売上割合・中間納付・法人の事業年度は未対応。税務上の助言ではありません。
