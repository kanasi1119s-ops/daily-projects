# LP草稿 / SNS告知文（Sales-Writer）
## キャッチコピー案
- 「本則か、簡易か。納税額を3秒で並べて比較」
- 「2割特例が終わった今、あなたの最適な方式は？」
- 「入力は端末の中だけ。登録不要の無料概算ツール」

## LP構成
**ヘッダー**: ゼイクラベ ― 消費税の納税額を、方式別に並べて比べる
**課題**: 2割特例の終了後、本則課税と簡易課税のどちらが自分に合うのか分かりにくい。
**解決**: 売上・仕入・業種を入力するだけで、本則課税・簡易課税・2割特例の納税額（概算）を一覧比較。
**特徴**: ①3方式を一画面で比較 ②登録不要・入力は送信されない ③スマホ対応
**使い方**: 1. 売上と仕入(税込)を入力 2. 業種区分を選択 3. 「比較する」
**料金（案・要検討）**: 基本機能は無料。将来案として、結果の保存用PDFレポートを有料提供する可能性あり（未決定）。
**注意書き**: 概算であり税務上の助言ではありません。申告前に税務署・税理士へご確認ください。標準税率10%のみ対応。
