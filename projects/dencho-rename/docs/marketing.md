# LP草稿・SNS告知文

## LP
**見出し**: 請求書PDFの名前付け、まとめて終わらせる。
**サブ**: 「日付_取引先_金額」に一括リネーム。ファイルはあなたのブラウザの外に出ません。

**こんな方に**: 個人事業主・フリーランス/経理担当が1人の小さなチーム/メールで受け取る請求書・領収書が溜まっている方

**機能**
- 取引年月日・取引先・金額を入れたファイル名を自動生成(リアルタイムプレビュー)
- ファイル名に日付があれば自動で日付を推測
- 重複名は自動で連番
- 索引簿CSV(新旧ファイル名・検索項目)を同梱してZIPで保存
- ブラウザ内で完結。インストール・アカウント登録不要

**料金プラン案(仮説・要検証)**: 無料(件数制限なし・基本機能) / 将来案: 買い切りの拡張版(OCR読み取り等)※未実装

**注意書き**: 本ツールはファイル名整理の補助です。電子帳簿保存法への適合を保証するものではありません。詳細は国税庁の資料または税理士へご確認ください。
