# 取引条件明示ジェネレーター

フリーランス新法(特定受託事業者に係る取引の適正化等に関する法律)第3条で求められる取引条件の明示事項を、抜け漏れなく書面化するブラウザ完結の静的ツール。

- 必須明示事項の未入力チェック
- 報酬支払期日が受領日から60日を超えていないかの警告(安全側に、受領日を1日目として計算)
- コピー / 印刷(PDF保存)
- 入力内容はブラウザ内のみで処理(送信・保存なし)、CSPで外部通信を遮断

## 起動
```
npm start        # http://localhost:5173
npm test         # ロジックの単体テスト(Node 22+, 依存なし)
npm run build    # dist/ に静的ファイルを出力
```
任意のE2E: `CHROMIUM_PATH=<chromium> node scripts/e2e.mjs`(playwright が必要)

## 構成
`src/logic.js` 純粋ロジック / `src/app.js` UI / `docs/` 法務・公開手順・マーケ素材・日次レポート

## 免責
法的助言ではありません。公開手順は `docs/PUBLISH.md`。
