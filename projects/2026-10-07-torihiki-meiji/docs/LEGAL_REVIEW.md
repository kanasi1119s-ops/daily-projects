# 法務チェック(Legal-Reviewer)

| 項目 | 結果 |
|---|---|
| 第三者コンテンツの権利 | 確認済: 画像・外部データ・外部フォント不使用。条文項目名のみ使用 |
| スクレイピング | 該当なし(外部取得なし) |
| 個人情報 | 確認済: 入力はブラウザ内のみ、送信・Cookie・localStorage不使用、CSPで外部通信遮断。★アクセス解析を導入する場合はプライバシーポリシー要 |
| 特商法表記 | ★要対応: 有料化(課金)する場合は事業者情報を人間が記入し表記が必要 |
| 誇大表現 | 確認済: 「法令遵守を保証」「必ず適法」等の表現なし。免責を画面・LPに記載 |
| 士業法リスク | ★要確認: 個別案件への法的判断を提供しない「雛形生成」に留めている。有料化前に弁護士へ表現確認を推奨 |
| 法令内容の正確性 | ★要確認: 明示事項(給付内容・報酬額・支払期日・当事者名・委託日・受領日/場所・検査完了日・現金以外の支払方法)と60日ルールを実装。施行状況・ガイドラインの最新を公取委・厚労省資料で人間が最終確認 |
