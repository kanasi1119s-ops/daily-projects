# 電帳法ファイル名ジェネレーター (denchou-namer)

領収書・請求書などのPDF/画像を、電子帳簿保存法の検索要件(取引年月日・取引金額・取引先)に沿った
`20261011_株式会社テスト_12000_領収書.pdf` 形式へ整えるブラウザ完結ツール。**ファイルは外部送信しません。**

## 起動
```bash
npm test          # ユニットテスト (Node 20+)
npm run build     # dist/ を生成(依存パッケージなし)
npm start         # http://localhost:5173 (http-server を npx で取得)
```
`index.html` を直接開くとESモジュールの制約で動かないため、必ずHTTPサーバー経由で開いてください。

## 機能 (MVP)
- 複数ファイルの一括入力、日付(西暦/和暦/全角)・金額(¥,円,カンマ)の正規化と検証
- 並び順3種、重複名への連番付与、禁則文字除去
- 名前を付けてダウンロード、索引CSV(BOM付UTF-8、CSV式インジェクション対策)
- CSPで外部通信を遮断、分析・Cookieなし

## 既知の制約
- ZIP一括は未対応(個別ダウンロード。ブラウザが複数DL許可を求める場合あり)
- マイナス金額(値引・返品)、1ファイル複数取引は未対応
- 命名ルールは `NFKC` 正規化を行う(例: ㈱→(株)、全角英数→半角)
- PDF内容のOCR自動入力は未実装(将来案。外部APIは使わない方針)
- 電帳法の全要件(タイムスタンプ、訂正削除履歴、事務処理規程等)の充足は保証しない
