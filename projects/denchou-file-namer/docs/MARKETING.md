# LP草稿
**見出し**: 領収書のファイル名、30秒で電帳法の検索条件に。
**サブ**: 日付・取引先・金額を入れるだけ。ファイルはあなたのブラウザの外に出ません。

**機能**
- 和暦・全角入力もOK。日付と金額を自動で整形・チェック
- 取引先名の禁則文字を自動除去、同名は連番で衝突回避
- 索引CSV付き(Excelで開いても文字化けしにくいUTF-8 BOM付き)
- アカウント登録・アップロード不要

**料金プラン案(仮説・要検証)**: 無料(基本機能) / 将来: 買い切りの一括ZIP・テンプレ保存など
**注意書き**: 本ツールは命名補助です。電子帳簿保存法への適合を保証するものではありません。
