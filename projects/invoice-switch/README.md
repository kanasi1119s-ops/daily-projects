# インボイス・スイッチ (invoice-switch)

個人事業主・フリーランス向けに、**インボイス登録する／しない**の年間負担を比較する静的Webツール。
免税のまま／2割特例／3割特例／簡易課税／本則課税を、対象年ごとの適用可否つきで並べて表示します。

> ⚠️ 本ツールは一般的な目安の試算であり、税務相談ではありません。制度値は `src/rules.js` に集約しており、
> 公開前に国税庁の一次情報で必ず確認してください（★要人間確認）。

## 起動
```bash
cd projects/invoice-switch
python3 -m http.server 8080   # ES Modules のため file:// ではなくHTTPで配信
# → http://localhost:8080/
```
## テスト
```bash
node --test test/
```
## 構成
- `index.html` / `src/app.js` UI（ビルド不要・依存なし）
- `src/calc.js` 純粋な計算ロジック
- `src/rules.js` 制度パラメータ（税率・みなし仕入率・特例の適用年）
- `test/calc.test.js` 単体テスト
- `docs/` 公開手順・法務チェック・QA記録・LP/SNS草稿・日次レポート

## 前提・制約（MVP）
- 標準税率10%のみ（軽減税率8%は未対応）。売上・仕入は税抜で入力。
- 2割/3割特例は「登録により初めて課税事業者になる個人」のみ対象として判定。
- 値引き要求などの取引先影響は**ユーザーの仮定入力**であり、予測ではありません。
