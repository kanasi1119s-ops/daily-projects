# LP草稿
**見出し**: インボイス、登録する？しない？ 5つの選択肢を1画面で比較
**サブ**: 免税のまま／2割特例／3割特例／簡易課税／本則課税。売上と経費を入れるだけで、年間負担の目安を並べて表示。
**特長**
- 2026年で終わる2割特例と、2027・2028年の個人向け3割特例を年ごとに判定
- 「適用できない理由」も表示。届出が必要なものは注記
- 入力は端末内で計算。登録不要・送信なし
**料金案（仮説）**: 基本無料。将来の有料案＝結果のPDF保存/複数シナリオ保存 月300円など（検証前の仮説）
**注意書き**: 一般的な目安であり税務助言ではありません。最新の制度は国税庁・税理士でご確認ください。

# SNS告知文（草稿）
1. 2割特例は2026年分で終了、2027〜28年は個人向けに3割特例。自分の場合どれが得か、売上と経費を入れて比べられる無料ツールを作りました。※目安です
2. インボイス登録、「しない」場合の値引き想定まで含めて並べて見られます。値引き率はあなたの仮定で変えられます。入力は送信されません。
3. 簡易課税と本則、特例、どれが合うか迷う方へ。適用できない理由も表示します。最終確認は国税庁/税理士で。
