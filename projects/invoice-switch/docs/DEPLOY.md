# 公開手順書（人間が実施）
ビルド不要の静的サイトです。`projects/invoice-switch/` 直下をそのまま配信できます。
1. **制度値の確認（必須）**: `src/rules.js` の値（2割特例=令和8年分まで／3割特例=令和9・10年分の個人／簡易課税みなし仕入率／各所得上限）を国税庁の一次情報と突き合わせる。
2. ホスティング選択（Cloudflare Pages / Netlify / GitHub Pages いずれも無料枠あり）。公開ディレクトリ＝`projects/invoice-switch`、ビルドコマンドなし。
3. ★独自ドメインを使う場合の取得・DNS設定は人間が実施。
4. 広告/アフィリエイトを載せる場合は、その旨の表記とプライバシーポリシー（外部送信規律）を整備。
5. 免責文・運営者情報（特商法表記が必要になる場合のみ）を記入。
6. 任意: `.github-workflow-example.yml` を `.github/workflows/` へ移してCI化。
