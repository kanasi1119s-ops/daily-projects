# 消費税 方式比較シミュレーター

個人事業主向けに、2割特例終了後の **3割特例（令和9・10年分）／簡易課税／本則課税** の納税額を並べて比較する静的Webツール。入力はブラウザ内で処理し、外部送信しない。

## 起動
```bash
npm test         # 計算ロジックのテスト（Node 18+、依存なし）
npm start        # http://localhost:5173
npm run build    # dist/ に静的ファイルを出力
```

## 構成
- `src/calc.js` 計算ロジック（純粋関数）
- `src/app.js` / `index.html` / `styles.css` UI
- `test/` ユニットテスト
- `docs/` 市場調査・法務・QA・公開手順・LP/SNS草稿

## 対象外（MVP）
法人／暦年以外の課税期間／複数事業区分の簡易課税／課税売上割合95%未満／端数処理の厳密再現。
税制は令和8年度改正（令和8年法律第12号）の解説に基づく。**要一次確認**。
