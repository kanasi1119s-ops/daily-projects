# LP草稿・SNS告知文(Sales-Writer)

## LP
**キャッチ案**
- 「発注書の“書き漏れ”に、早めに気づく。」
- 「フリーランスへの発注条件を、3分で整理。」

**ヒーロー**: フリーランスに仕事を頼む前に、取引条件の明示事項と支払期日をチェック。入力した内容はブラウザの中だけで処理されます。

**特長**
1. 明示事項の漏れを確認 — 業務内容・報酬・支払期日・受領日などの必須項目を入力しながら点検
2. 支払期日(受領日から60日以内)の目安を即判定
3. 通知書のテキストをコピー・印刷
4. 登録不要・入力データは送信されません

**料金案(仮説・要検討)**: 基本機能は無料。将来、PDF出力やテンプレ保存を有料オプション化する案。

**注意書き**: 本ツールは情報提供であり法的助言ではありません。法令適合を保証するものではありません。
