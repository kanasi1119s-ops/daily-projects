# 取引条件ノート (torihiki-note)

フリーランスに業務を発注する事業者向けに、**フリーランス法(特定受託事業者に係る取引の適正化等に関する法律)** の
第3条(取引条件の明示)・第4条(支払期日=受領日から60日以内)を確認しながら、取引条件通知書のテキストを作るブラウザ完結ツール。

- 入力データはブラウザ内のみで処理(外部送信・保存なし)
- 依存パッケージなし(Node 20+ があれば動作)
- 法的助言ではありません(画面フッターにも明記)

## 起動
```
npm test          # ユニットテスト(node:test)
npm start         # http://localhost:8080 (PORT で変更可)
npm run build     # dist/ に静的ファイルを出力
```

## 構成
- `src/validate.js` 必須項目・日付・60日ルールの判定
- `src/render.js` 通知書テキスト生成・禁止行為セルフチェック項目
- `src/app.js` / `index.html` / `style.css` UI
- `docs/` 日次レポート・法務チェック・公開手順書・LP/SNS草稿・QA記録

## MVPスコープ
含む: 第3条の明示事項チェック、60日ルール判定、通知書テキスト生成/コピー/印刷、禁止行為セルフチェック一覧
含まない: PDF出力、ログイン・保存、契約書全文の生成、下請法(取適法)対応、決済
