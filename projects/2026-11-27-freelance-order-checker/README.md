# フリーランス法 発注チェッカー (MVP)

発注側事業者向けに、①取引条件の発注書ひな形生成 ②支払期日(受領日から60日)の判定 ③禁止行為などのセルフ診断 を行う静的Webツールです。入力はブラウザ内で処理され、サーバー送信・外部APIはありません。**法的助言ではなく参考情報です。**

## 起動
```
npm test        # ロジックのユニットテスト
npm start       # http://localhost:8080
npm run build   # dist/ に静的ファイルを出力
```
## 構成
- `index.html` / `app.js` UI、`lib/logic.js` ロジック、`test/` テスト
- `docs/` 公開手順書・法務チェック・LP/SNS草稿・QA記録

## 既知の制約
- 再委託の特則(元委託の支払期日から30日)、下請法(取適法)との関係は未対応
- 60日計算は受領日を1日目とする保守的な計算。条文・公式資料で要確認
- 診断項目は主要論点のみ(8問)。網羅的ではない
