# LP草稿・SNS告知文(コピペ用・効果を保証しません)
## LP
**見出し**: 発注前の「うっかり」を、3分で見直す。
**サブ**: フリーランスへの発注条件(業務内容・報酬・支払期日)のひな形づくりと、支払期日・禁止行為のセルフチェックをブラウザだけで。入力内容は外部に送信されません。
**機能**: ①取引条件の発注書ひな形(未記入項目をお知らせ) ②受領日から60日の支払期日判定 ③8問のセルフ診断
**料金案(仮説)**: 基本機能は無料 / 将来案: PDF出力・テンプレ複数・チーム共有を月額で提供(未実装・要検証)
**注意書き**: 参考情報であり法的助言ではありません。最終確認は公式資料・専門家で。
## SNS
1. フリーランスに発注する会社さん向けに、発注書ひな形と支払期日(60日)チェックができる無料ツールを作りました。入力はブラウザ内だけで処理されます。※参考情報です
2. 「支払期日、受領日から数えて大丈夫?」を日付入力だけで確認。発注時の明示事項の抜け漏れチェックも。#フリーランス法 #発注 (法的助言ではありません)
3. 8問のセルフ診断で、発注まわりの見直し候補を整理。小さなチームの発注ルール作りの叩き台にどうぞ。
