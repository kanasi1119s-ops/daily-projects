# 電帳法ファイル名リネーマー

請求書・領収書などの電子取引データを `取引年月日_取引先_金額.拡張子` に一括リネームし、検索簿CSVを出力するブラウザ完結ツール。依存パッケージなし・サーバー不要・ファイルは外部送信されません。

## 起動
```
npm test        # ユニットテスト(node:test)
npm start       # http://localhost:5173
npm run build   # dist/ に静的ファイルを出力
```

## 構成
- `src/core.js` 日付/金額の正規化、ファイル名生成、重複回避、CSV、最小ZIPライタ(DOM非依存)
- `src/app.js` UI(ドラッグ&ドロップ、行編集、ZIP/CSV出力)
- `docs/` 法務チェック・公開手順・LP/SNS草稿

## 既知の制約
- OCRによる自動読取は未実装(手入力)。
- ZIPは無圧縮(STORE)、合計1GBまで。
- 電帳法適合を保証するものではない(docs/legal-check.md 参照)。
