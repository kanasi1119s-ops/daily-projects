# 法務チェック(Legal-Reviewer)

| 項目 | 判定 | 備考 |
|---|---|---|
| 第三者コンテンツ | OK | 画像・文章・データの同梱なし。ユーザーのファイルはブラウザ内処理のみ |
| スクレイピング | 該当なし | 外部サイト取得なし。CSPで`connect-src 'none'` |
| 個人情報 | OK(要確認) | 外部送信・保存なし。アクセス解析等を追加する場合はプライバシーポリシーが必要 → **人間が最終確認** |
| 特定商取引法 | 要対応 | 有料化する場合は特商法表記が必要。事業者情報の記入は**人間が行う** |
| 誇大表現 | OK | 「適合を保証」等の表現なし。LP草稿はSelf-check済み |
| 税務・法令の表現 | 要確認 | 「電帳法対応」と断定せず「検索要件に沿ったファイル名づくりを補助」と表記。公開前に税理士等の確認を推奨 |
