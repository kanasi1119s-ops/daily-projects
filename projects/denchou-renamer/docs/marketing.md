# LP草稿 / SNS告知文

## キャッチコピー案
- 「日付_取引先_金額」へ、ドラッグ&ドロップでまとめて整える
- 領収書PDFの名前付けを、ブラウザだけで

## LP本文
**電帳法ファイル名リネーマー**
メールやダウンロードで受け取った請求書・領収書のファイル名を、取引年月日・取引先・金額の形式に一括で整えます。

- ファイルは端末内で処理。サーバーへ送信しません
- 全角数字・カンマ・「円」付きの金額も自動で正規化
- 同名ファイルは自動で連番を付与
- 検索簿CSVとリネーム済みZIPをワンクリックで出力

**料金プラン案(仮説・要検証)**: 無料(1回10件まで)/ 個人 月額300円〜(件数無制限)
※本ツールは検索要件に沿ったファイル名づくりの補助です。法令への適合を保証するものではありません。

## SNS告知文
1. 電子取引の領収書、ファイル名どうしてますか?「日付_取引先_金額」に一括変換するブラウザツールを作りました。ファイルは外部送信なし。
2. 確定申告前の領収書整理に。ドラッグ&ドロップ→日付・取引先・金額を入力→ZIPでダウンロード。検索簿CSVも出ます。
3. 【個人開発】請求書PDFの名前付けを楽にするツール。インストール不要、ブラウザ完結です。ご意見ください!
