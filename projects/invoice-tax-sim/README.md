# インボイス税額シミュレーター

個人事業者向け。免税のまま/本則課税/簡易課税/2割特例(2026年分)・3割特例(2027〜2028年分・予定)の消費税額を比較し、免税のままの場合に取引先が負担する控除不能額の目安も表示する静的Webアプリ。**入力は端末内のみで処理(外部送信・保存なし)。**

## 起動
```
npm i
npm run dev      # 開発サーバ
npm test         # 計算ロジックのテスト
npm run build    # dist/ に静的ファイル出力
```
## 構成
- `src/calc.ts` 計算ロジック(純関数) / `src/main.ts` UI / `tests/` vitest
- `docs/` 法務レビュー・公開手順書・LP/SNS草稿

## 既知の制約
標準税率10%のみ、軽減税率・基準期間/課税期間の厳密判定・届出要否は未対応。制度数値は税理士系二次情報に基づくため国税庁原文で要確認。
