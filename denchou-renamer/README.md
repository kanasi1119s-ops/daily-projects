# 電帳法リネーマー

請求書・領収書などの電子取引データを、電子帳簿保存法の検索要件（取引年月日・取引金額・取引先）に沿って
`YYYYMMDD_取引先_金額_書類種別.拡張子` に統一リネームし、索引簿CSVとあわせてZIPで書き出す、**ブラウザ完結**の静的ツールです。
ファイルは外部送信されません（CSPで`connect-src 'none'`）。

## 起動
```
npm start        # http://localhost:8080 （python3 が必要）
npm test         # ロジックの単体テスト（Node 20+）
```
ビルド不要の静的サイト（`src/` をそのまま配信）。

## 構成
- `src/lib.js` 純関数（日付/金額検証、命名、重複回避、CSV、ZIP生成）
- `src/app.js` UI、`src/index.html`
- `test/` 単体テスト、`docs/` 法務・公開手順・マーケ素材

## MVPスコープ
含む: 複数ファイルのドロップ、手入力、重複名回避、索引CSV(BOM付き/CSV式無害化)、ZIP出力
含まない: OCR自動読取、タイムスタンプ付与、クラウド保存、アカウント機能
