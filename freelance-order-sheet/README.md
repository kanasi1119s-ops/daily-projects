# 取引条件明示書メーカー（freelance-order-sheet）

フリーランスへ業務委託する発注側向けに、**フリーランス新法の取引条件の明示事項**を入力 → **抜け漏れ・支払期日60日ルールをチェック** → **テキスト/印刷(PDF)で出力**する、ブラウザ完結の静的ツール。入力データは外部送信しません。

> ⚠ 法的助言ではありません。明示事項は公正取引委員会・厚生労働省等の一次情報で必ず確認してください（本開発環境では一次情報サイトへ接続できず、項目は二次情報と知識に基づく＝**要確認**）。

## 起動
```
npm start        # http://localhost:8080 (PORT で変更可)
npm test         # ロジックの単体テスト (node:test)
npm run build    # dist/ に静的ファイルを出力
```
依存パッケージなし（Node 20+）。

## 構成
- `src/logic.js` 検証・文書生成（純粋関数）
- `src/app.js` UI 配線 / `index.html` / `style.css`
- `tests/` テスト / `docs/` 企画・法務・公開手順・LP・SNS

## 実装済みチェック
必須項目の未入力、納期〜支払期日が60日超（エラー）/ちょうど60日（警告）、検査ありの検査完了日、現金以外支払の詳細、報酬額または算定方法、再委託時の元委託支払期日、日付整合性。
