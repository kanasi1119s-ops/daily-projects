# フリーランス取引条件 明示書メーカー

フリーランス(特定受託事業者)との取引で必要な取引条件の明示事項を入力し、書面テキストを生成する静的Webツール。
サーバー不要・入力内容はブラウザ内のみで処理(localStorageに自動保存)。

## 機能(MVP)
- 明示事項フォーム(業務内容/報酬額/支払期日/納品日・場所/検査完了日/支払方法 等)
- 入力チェック(必須漏れ、日付不正、支払期日が納品日から60日超の警告)
- プレビュー、テキストコピー、印刷/PDF保存
- 発注側の禁止行為セルフチェックリスト
## 含まない
アカウント、サーバー保存、電子署名、決済、契約書全文の自動生成

## 起動
```
npm install
npm run dev      # 開発
npm test         # ロジックのユニットテスト
npm run build    # dist/ に静的ファイル出力
```
## 注意
法的助言ではありません。条文・運用は公正取引委員会の公式情報で確認してください。
