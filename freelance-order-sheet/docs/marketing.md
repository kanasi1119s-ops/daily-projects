# LP草稿 / SNS告知文（Sales-Writer）
## LP
**見出し**: フリーランスに発注するとき、取引条件の明示は大丈夫ですか？
**サブ**: 項目を入力するだけで、抜け漏れと支払期日をその場でチェック。入力内容はブラウザの外に出ません。
**特長**
- 明示すべき項目を順に入力（業務内容・納期・場所・検査・報酬・支払期日など）
- 納期から60日を超える支払期日を自動で指摘
- テキストコピー／印刷でそのまま書面化
- 登録不要・サーバー送信なし
**料金案（仮説）**: 基本機能 無料。将来、案件保存・テンプレ追加を有料化する可能性（未確定）
**注意書き**: 本ツールは項目整理の補助であり法的助言ではありません。最終確認は公式情報・専門家で。

## キャッチコピー案
1. 「書き忘れ」を送信前に見つける、発注書チェック
2. 60日ルール、うっかりを防ぐ
3. 入力はブラウザの中だけ。

## SNS（草稿）
A: フリーランスへの発注時の取引条件明示、項目の抜けがないか不安…という方向けに、入力→チェック→書面化できる無料ツールを作りました。入力データは送信されません。※法的助言ではありません。
B: 「支払期日は納期から60日以内」を自動チェック。発注担当者向けの小さなツールです。最終確認は公式情報で。
C: 発注書のテンプレを探す前に、まず項目の抜け漏れチェックから。ブラウザだけで動きます。
Self-check: 効果・収益の保証表現なし、「適法を保証」表現なし。
