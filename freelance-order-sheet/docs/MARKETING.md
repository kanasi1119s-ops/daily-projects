# LP草稿・SNS告知文
## LP
**キャッチ**: 「発注書なしで仕事を受けていませんか? 取引条件を5分で書面に。」
**サブ**: フリーランス・個人事業主と、発注する側のための取引条件 明示書メーカー。ブラウザ内で完結、入力内容は送信されません。
**機能**
- 明示が求められる項目を、抜け漏れなく入力できるフォーム
- 支払期日が納品日から60日を超えていないか自動で警告
- テキストコピー・印刷/PDF保存
- 発注側の禁止行為セルフチェックリスト
**料金案(仮説・要検証)**: 基本機能は無料。テンプレ集・複数案件管理は有料プラン(月額数百円〜)を検討。
**免責**: 本ツールは法的助言ではありません。最終判断は公式情報・専門家でご確認ください。
## SNS
1. 口約束で始まった仕事、あとで揉めた経験ありませんか? 取引条件をまとめて書面にできる無料ツールを作りました。入力はブラウザ内だけで処理されます。
2. 発注する側の方へ: 業務内容・報酬・支払期日などの明示事項を、フォームに沿って入力するだけ。支払期日の60日チェック付き。(法的助言ではありません)
3. 「発注書、毎回ゼロから作ってる…」を減らしたくて作りました。コピー&PDF保存に対応。ご意見ください!
