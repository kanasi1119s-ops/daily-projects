# インボイス経過措置 控除額計算機

免税事業者等（インボイス発行事業者以外）からの課税仕入れについて、取引日ごとの控除割合（80%→70%→50%→30%→0%）を自動判定し、仕入税額控除の**目安**を計算するブラウザ完結の静的ツールです。

- 入力はブラウザ内で処理され、サーバー送信・保存はしません
- 1件ずつ入力、またはCSV/表の貼り付け取込、結果のCSV出力に対応
- 1億円/年の適用上限を取引日順に反映

## 起動

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 単体テスト (vitest)
npm run build    # 型チェック + 本番ビルド (dist/)
```

## 構成

| パス | 内容 |
|---|---|
| `src/schedule.ts` | 控除割合スケジュール（**法改正時はここだけ更新**） |
| `src/calc.ts` | 計算・CSVパース・CSV出力 |
| `src/main.ts` | UI（DOM操作は textContent のみ） |
| `tests/calc.test.ts` | 境界日・上限・パース・CSVインジェクションのテスト |
| `docs/` | 法務チェック・公開手順・LP/SNS草稿・QA記録 |
