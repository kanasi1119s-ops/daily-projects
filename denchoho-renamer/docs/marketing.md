# マーケ素材(Sales-Writer)

※ 収益・税務上の効果を保証する表現は含めていません。

## LP草稿
**見出し**: 領収書のファイル名、まとめて「日付_取引先_金額」に。
**サブ**: ブラウザの中だけで処理。ファイルは外部に送信されません。

**特徴**
- ドラッグ&ドロップで複数ファイルを一括リネーム
- 全角/半角・カンマ・和暦以外の日付表記ゆれを自動で正規化
- 同名ファイルは自動で連番
- 検索用の索引CSVも同時に出力(Excelで開けます)
- インストール不要・アカウント不要

**使い方**: ①ファイルを入れる ②日付・取引先・金額を入力 ③ZIPをダウンロード

**料金案(仮説)**: 無料(広告・関連サービス紹介で運用)/ 将来案: 有料でOCR自動入力(要・追加調査と有料API契約=人間判断)

**注意書き(必須)**: 本ツールは法的助言ではありません。電子帳簿保存法の要件の確認は税理士・税務署にご相談ください。
