# 請求額かんたん計算

消費税(10%/8%/非課税)と源泉徴収税を**税率ごとに1回だけ端数処理**して計算し、**手取り(振込額)から必要な請求額を逆算**できる、ブラウザ完結の静的Webツール。入力データは外部送信しません。

## 起動
```bash
npm install
npm run dev      # 開発サーバー
npm test         # ユニット/総当たりテスト(24件)
npm run build    # dist/ に静的ファイル出力
```

## 構成
- `src/calc.ts` 計算ロジック(純関数) / `src/main.ts` UI / `tests/` テスト
- `docs/` QA結果・法務チェック・公開手順・LP/SNS草稿

## MVPスコープ
含む: 税率別集計、税込/税抜入力、端数処理3種、源泉徴収(10.21% / 100万円超部分20.42%)、手取り逆算(10%課税)
含まない: 請求書PDF出力、保存機能、インボイス登録番号管理、簡易課税・2割/3割特例の判定
