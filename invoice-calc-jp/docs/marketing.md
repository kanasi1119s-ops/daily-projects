# LP草稿
**見出し**: 請求書の消費税・源泉徴収・インボイス経過措置を、入力するだけで計算
**サブ**: ブラウザ内で完結。入力内容は送信・保存されません。
**機能**: 税抜/税込の相互計算（10%・8%）／端数処理の切替／源泉徴収（100万円超の税率対応）／免税事業者への支払いの控除目安
**料金案（仮説）**: 基本無料。将来的に請求書PDF出力などを有料化する案（未検証）
**免責**: 計算結果は目安です。税務判断は税理士・国税庁の情報でご確認ください。

# SNS告知文
1. 請求書の「税込から逆算」「源泉いくら引かれる？」をまとめて計算できる無料ツールを作りました。入力内容は送信されません。
2. インボイス：免税事業者に払った分は、取引日で控除できる割合が変わります（80%→50%）。目安を出せるツールです。※要確認
3. フリーランスの請求書計算、端数処理（切捨/四捨五入/切上）の違いもすぐ比較できます。
