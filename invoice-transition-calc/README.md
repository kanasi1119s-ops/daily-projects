# インボイス経過措置 控除額シミュレーター

免税事業者等(未登録事業者)からの仕入れについて、経過措置(控除率 80%→70%→50%→30%)による**控除できない消費税額**を試算する静的Webツール。依存パッケージなし・計算はすべてブラウザ内。

## 起動
```
npm test        # ロジックのユニットテスト
npm run build   # public/ + src/calc.js → dist/
npm start       # http://localhost:5173
```

## 構成
- `src/calc.js` 計算ロジック(DOM非依存・テスト対象)
- `public/` UI(ビルド時に calc.js を同梱)
- `docs/` 法務チェック・公開手順・LP/SNS草稿

## MVPの範囲
含む: 控除率スケジュール判定、税込/税抜、税率8/10%、端数処理選択、複数行・合計。
含まない: 2割/3割特例、少額特例、事業者規模による適用制限、CSV入出力、保存機能。

控除率の根拠は令和8年度税制改正後の報道・解説ベース。**公開前に国税庁の一次情報で再確認すること。**
