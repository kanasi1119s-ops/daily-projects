# インボイス経過措置 試算ツール

適格請求書発行事業者以外（免税事業者等）からの仕入に係る**仕入税額控除の経過措置**（2026/10以降は控除割合が段階的に縮小）について、取引ごと・年間支払額ごとの「控除できない消費税額」を試算する、依存ゼロの静的Webツール。

## 起動
```
npm test          # 単体テスト (node:test)
npm run build     # dist/ に静的ファイルを出力
npx serve dist    # または任意の静的サーバで dist/ を配信（ES modules のため file:// 不可）
```

## 構成
- `src/rates.js` 控除割合・少額特例の定義（法改正時はここだけ更新）
- `src/calc.js` 純粋関数の計算ロジック（整数演算、1円未満切り捨て）
- `src/app.js` / `index.html` UI（入力はブラウザ内のみで処理）
- `docs/` QA結果・法務チェック・公開手順・マーケ素材

## MVPスコープ
含む: 取引別試算、少額特例トグル、年間支払額からの見通し表。
含まない: 簡易課税/2割特例の計算、CSV取込、保存機能、決済。
