# インボイスチェッカー
適格請求書(インボイス)の記載事項・税率別税額・端数処理をチェックする静的Webツール。**入力データはブラウザ内のみで処理**(外部送信なし、依存パッケージなし)。

## 起動
```
npm start        # http://localhost:5173 (PORT=任意)
npm test         # 単体テスト(node:test)
npm run build    # dist/ に静的ファイルを出力
```
## 構成
- `src/core.js` 検証ロジック(登録番号チェックデジット、税額計算、記載事項チェック)
- `src/index.html` / `app.js` / `style.css` UI
- `docs/` 日次レポート・法務チェック・公開手順・LP/SNS草稿・既知課題

## MVP範囲
含む: 適格請求書/簡易請求書の記載事項チェック、登録番号形式+チェックデジット、税率別集計と税額照合、軽減税率の※確認。
含まない: PDF/画像読取、国税庁APIでの実在確認、請求書作成・保存、アカウント機能。
