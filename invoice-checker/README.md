# 適格請求書チェッカー

ブラウザだけで動く、適格請求書（インボイス）の必須項目チェック＋請求書プレビュー/PDF保存ツール。ビルド不要の静的サイトで、入力データは外部送信されません。

## 機能
- 必須記載事項チェック（発行者名・登録番号 T+13桁・取引年月日・品目・税率）
- 法人番号チェックデジット検証（不一致は警告。個人事業者は対象外）
- 税率ごと合計後に1回だけ端数処理（切捨/四捨五入/切上）
- 軽減税率(8%)の「※」自動付与
- 印刷→PDF保存

## 起動
```
npm start   # http://localhost:8080
npm test    # ロジックの単体テスト
```

## 公開手順（人間が実施）
1. 静的ホスティング（GitHub Pages / Cloudflare Pages / Vercel 等）で `invoice-checker/` をルートに指定。ビルドコマンドなし。
2. 独自ドメインを使う場合は取得・DNS設定を人間が実施。
3. 公開前に `docs/legal-checklist.md` の「要対応」を解消。

## 既知の制約
- 値引き行（マイナス単価）は未対応（エラー表示）
- 保存機能なし（リロードで消える）。将来は localStorage 保存を検討
- 登録番号の実在確認（国税庁API）は未実装。外部API利用規約の確認が必要
- 税務上の助言ではありません
