# LP草稿
**見出し**: 請求書の「抜け」を、送る前にチェック。
**サブ**: 登録番号・税率ごとの消費税・軽減税率の「※」まで確認。入力内容はブラウザの外に出ません。
**特長**
- 必須項目チェック（登録番号の形式・法人番号チェックデジット）
- 税率ごとに合計して1回だけ端数処理
- そのままPDF保存
- インストール・会員登録不要
**料金プラン案（仮説・要検証）**: 無料: 単発チェック／有料案: 取引先・品目テンプレ保存、一括チェック（月額は検証後に決定）
**注意書き**: 本ツールは税務・法律上の助言ではありません。
