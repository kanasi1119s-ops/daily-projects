# フリーランス新法 支払期日チェッカー

受領日と契約上の支払期日から「60日以内」の目安を判定し、取引条件の明示項目を整理・コピーできる静的Webツール。入力は全てブラウザ内で処理され、外部送信しません。

## 起動
```
npm install
npm run dev      # 開発
npm test         # ユニットテスト
npm run build    # dist/ に静的ファイルを出力
```
## 構成
- `src/logic.ts` 判定・文面生成ロジック(テスト対象) / `src/main.ts` UI / `docs/` 法務チェック・公開手順・LP/SNS草稿

## 既知の制約
- 受領日を1日目として数える簡易判定。締め日方式の扱い・再委託の特例・祝日の扱いは未対応/要確認。
- 法的助言ではありません。
