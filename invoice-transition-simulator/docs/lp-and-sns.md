# SNS告知文
1. 10/1から、免税事業者からの仕入れの控除割合が80%→70%に(経過措置)。取引日ごとに「控除できない額」を出せる無料ツールを作りました。※概算・要公式確認
2. 個人事業主の消費税、2割特例は令和8年分まで。令和9・10年分は3割特例の予定。本則・簡易と並べて比較できます。入力は端末内で完結。※概算です
3. 「うちの取引先、控除どれだけ減る？」を1分で確認できるシミュレーターを公開準備中。制度の適用要件は公式情報でご確認ください。
