# インボイス経過措置・3割特例シミュレーター

個人事業主向けの静的Webツール。2026/10/1の仕入税額控除70%化と、2割特例(〜令和8年分)→3割特例(令和9・10年分)を、本則・簡易課税と並べて概算比較します。入力値は端末内のみで処理され、送信・保存しません。

## 機能
- A. 免税事業者等からの仕入れの「控除できない額」を取引日から自動判定(80→70→50→30→0%)
- B. 本則 / 簡易 / 2割 / 3割特例の納付税額比較(国税+地方消費税の概算)

## 起動
```
npm test          # ロジックのユニットテスト(Node 20+)
npm start         # http://localhost:8080 (ES Modulesのためfile://不可)
npm run build     # dist/ に静的ファイルを出力
```

## 構成
- `src/logic.js` 純関数の計算ロジック / `src/app.js` UI / `test/` テスト
- `docs/` 要件・法務レビュー・公開手順書・LP/SNS草稿

## 制約
税制は令和8年度税制改正大綱ベースで、適用要件の判定は行いません。詳細は `docs/legal-review.md`。
