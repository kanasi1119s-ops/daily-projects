# LP草稿
**見出し**: 「納品から60日」、数え間違えていませんか?
**サブ**: 受領日を入れるだけ。支払期日・遅延利息の目安・適用される法律の目安を、ブラウザ内で確認。入力は送信されません。
## 機能
- 支払期日(受領日から60日目)と遅延利息の目安
- 「月末締め翌月末払い」など締め日運用が60日を超えないかを1年分チェック
- 取適法/フリーランス法の適用目安
- 発注書(取引条件の明示)チェックリスト
## 料金プラン案(仮説・要検証)
無料(基本機能)/ 将来案: 士業・発注担当向けの有料版(複数案件管理・PDF出力)。※現時点で課金機能なし。
## 注意書き
本ツールは目安であり法的助言ではありません。最終判断は公式情報・専門家にご確認ください。
# SNS告知文(草稿)
1. 「受領日から60日以内」の数え方、ざっくりで済ませていませんか? 受領日を入れるだけで期日と、月末締め翌月末払いが超過しないかを確認できる無料ツールを作りました。入力はブラウザ内だけで処理されます。※法的助言ではありません
2. 取適法とフリーランス法、どっちが関係する?を目安で判定する小さなツールを公開準備中です。基準値は必ず公式資料で最終確認を。
3. 発注書に書くべき項目のチェックリスト付き。フリーランスの方も発注する側の方も、取引前の確認にどうぞ。
