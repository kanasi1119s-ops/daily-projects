# LP草稿
**キャッチ**: 寄付の「期限」と「やること」を、ひと目で。
**サブ**: ふるさと納税の寄付を記録するだけで、年内決済・ワンストップ申請書の締切と未完了タスクを自動表示。
**機能**: 寄付一覧管理 / 期限カウントダウン / 上限額との差分表示 / 5自治体超・確定申告併用の警告 / CSV・JSONバックアップ / データは端末内のみ保存
**料金案**: 無料（仮説：広告または将来の有料バックアップ機能で検証）
**注意書き**: 本ツールは記録補助です。税額計算・税務判断は行いません。
# SNS草稿
1. ふるさと納税、どこに寄付したか・申請書は出したか、忘れていませんか？期限カウントダウン付きの無料メモツール作りました。データは端末内だけに保存。
2. ワンストップ特例は5自治体まで・申請書は翌年1/10必着。寄付ノートなら6自治体目で警告が出ます（制度の詳細は公式情報をご確認ください）。
3. 年末の駆け込み前に、寄付の合計と上限額（シミュレーターで確認した金額）の差をチェック。CSV出力で確定申告の準備にも。
