# 法務チェック (Legal-Reviewer)
- [x] 第三者コンテンツ: 画像・文章・データの転載なし。自治体名はユーザー入力のみ。
- [x] スクレイピング: 行わない。外部通信なし。
- [x] 個人情報: 外部送信・サーバ保存なし（localStorageのみ）。**要人間確認**: 公開時に「データは端末内のみ」の説明を含むプライバシーポリシーを最終確認。アクセス解析を入れる場合は別途ポリシー更新が必要。
- [x] 特商法: 無料・物販/役務提供なし。有料化する場合は特定商取引法に基づく表記が必要（事業者情報の記入は人間が行う）。
- [x] 誇大表現: 「節税できる」「必ず得」等の効果保証を使わない。税額計算は行わない旨をフッターに明記。
- ★要対応: 税務に関する説明（5自治体・1/10必着・2,000円目安）は公開前に総務省/国税庁の最新情報で人間が再確認。
