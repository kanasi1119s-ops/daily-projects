# LP草稿・SNS告知文(コピペ用)
※「適法の保証」「罰則回避」等の断定表現は使っていません。

## LP
**見出し**: フリーランスへの発注、書面の抜け漏れを3分で確認。
**サブ**: 取引条件明示書づくり・60日期日・禁止行為チェックを、ブラウザだけで。入力内容は送信されません。

**こんな方へ**: フリーランスに初めて外注する/毎回の発注書の項目に自信がない/支払サイトが60日を超えていないか気になる

**機能**
- 取引条件明示書ジェネレーター(必須項目の入力漏れを指摘、コピー・txt保存・印刷/PDF)
- 支払期日チェッカー(受領日から60日以内の上限日を自動計算)
- 禁止行為セルフチェック(7類型)
- 登録不要・無料・端末内で処理

**料金プラン案(仮説)**: 基本機能 無料 / 業種別テンプレパック(予定) / チーム向け履歴保存(予定)

**注意書き**: 本ツールは情報整理と書面作成の補助であり、法的助言ではありません。取適法(改正下請法)の対象となる取引では別途の対応が必要な場合があります。

## SNS告知文
1. 「フリーランスに発注するとき、取引条件の書面ってちゃんと出せてる? 必須項目の確認から支払期日(60日以内)の計算まで、ブラウザだけでできる無料ツールを作りました。入力内容は送信されません。 #フリーランス法 #個人開発」
2. 「『月末締め翌月末払い』でも、月初納品だと60日を超えることがあるって知ってました? 受領日を入れるだけで上限日がわかるチェッカーを公開準備中です。 #フリーランス新法」
3. 「発注側のセルフチェック用に、フリーランス法の禁止行為7類型をチェックリスト化しました。法的助言ではありませんが、見直しのきっかけに。 #発注 #外注」
キャッチコピー案: 「発注の抜け漏れ、出す前に3分チェック」
