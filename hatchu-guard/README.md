# 発注ガード (hatchu-guard)

フリーランスに業務を発注する事業者向けの、**取引条件明示書(フリーランス法 第3条書面)ジェネレーター**。
あわせて **報酬の60日期日チェック** と **7つの禁止行為セルフチェック** を備えた、ブラウザ完結の静的Webツールです。

- ターゲット: フリーランスに発注する小規模事業者・個人事業主・スタートアップ
- 入力内容は端末内で処理され、サーバー送信・保存はありません(依存パッケージもゼロ)

## 起動
```bash
npm start          # http://localhost:5173
npm test           # ロジックの単体テスト
npm run build      # dist/ に静的ファイルを出力
```
Node.js 20 以上。

## 構成
```
index.html / style.css
src/logic.js   純粋ロジック(日付・検証・文面生成・禁止行為)
src/app.js     DOM層
tests/         node:test
scripts/       build.js / serve.js
docs/          QA.md LEGAL.md DEPLOY.md MARKETING.md BUSINESS.md
```

## MVPスコープ
含む: 明示書生成(コピー/txt保存/印刷)、60日上限日計算、禁止行為チェック、免責表示
含まない: アカウント、保存/履歴、PDF直接生成、決済、電子署名、取適法(改正下請法)対応の分岐

> 本ツールは法的助言ではありません。法令解釈は一次資料(公正取引委員会・厚生労働省)で最終確認してください。
