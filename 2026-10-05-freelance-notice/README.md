# フリーランス法 取引条件通知書メーカー

フリーランス法（特定受託事業者に係る取引の適正化等に関する法律）第3条の明示事項の抜け漏れをチェックしつつ、取引条件通知書を作成する静的Webツール。入力内容はブラウザ内のみで処理（外部送信なし）。

## 起動
```
npm install
npm run dev        # 開発
npm test           # ユニットテスト(16件)
npm run build      # 本番ビルド → dist/
npx vite preview --port 4173 &  node tests/e2e.mjs   # 簡易E2E(CHROMIUM環境変数で実行パス指定可)
```

## 機能
- 明示事項の入力と未記入・日付矛盾のリアルタイム指摘
- 受領日から60日以内の支払期日判定（受領日を1日目とする初日算入。要確認）
- 通知書テキストのコピー／印刷(PDF保存)

## 未実装・制約
- 再委託の例外、休日による支払期日の扱い、月末締めの自動計算は未対応
- 通知書は雛形。法的助言ではない
- 費用の追加・取引条件変更の通知機能なし

構成: `src/logic.ts`(純粋ロジック) / `src/main.ts`(UI) / `tests/`
