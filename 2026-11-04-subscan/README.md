# SubScan

カード/銀行の明細CSVから、毎週・毎月・毎年の**定期支払い(サブスク)を自動検出**し、年間コストと次回請求目安を表示、解約検討用リマインダー(.ics)を出力するブラウザ完結ツール。

- 依存パッケージなし(Node 20+ のみ)。ビルド不要の静的サイト
- CSVは**ブラウザ内でのみ処理**。外部送信・保存なし(`fetch`はサンプル取得のみ)

## 起動
```bash
npm start        # http://localhost:8080 (PORT=... で変更可)
npm test         # ユニットテスト
```
`index.html` は ES Modules を使うため、`file://` ではなく上記サーバー(または任意の静的ホスティング)経由で開いてください。

## 構成
| パス | 内容 |
|---|---|
| `src/csv.js` | CSV解析(引用符/BOM/タブ)、Shift_JIS判定、列推定 |
| `src/detect.js` | 日付/金額解析、店名正規化、周期検出、ICS生成 |
| `src/app.js` | UI(DOMはtextContentのみ使用) |
| `test/` | `node:test` によるテスト |
| `docs/` | 法務チェック・公開手順・LP/SNS草稿 |

## 検出ロジック概要
店名を正規化してグルーピング → 取引間隔の中央値が 7/30/365 日付近 かつ 金額が中央値±15%に6割以上収まる場合に定期支払いと判定。

## 既知の制約
- 年額プランは明細に2年分以上ないと検出不可(1年間隔の2件が必要)
- 日付は西暦表記のみ対応(和暦・年なし表記は未対応)
- 同一サービスで店名表記が月ごとに大きく変わる場合は別扱い
- 外貨建て・為替変動で金額が15%超ぶれると検出漏れ
- 判定はあくまで推定。誤検出/見逃しあり
