# 法務レビュー記録 (2026-11-04)

| 項目 | 判定 | 備考 |
|---|---|---|
| 第三者コンテンツ(画像/文章/データ) | ✅ 問題なし | 同梱はダミーのサンプルCSVのみ。サービス名(NETFLIX等)はサンプル中の例示で、実在サービスのロゴ・画像は不使用。LP公開時も社名・ロゴの無断使用は避ける |
| スクレイピング | ✅ 該当なし | 外部サイト取得なし |
| 個人情報 | ⚠️ 要人間確認 | 現状は端末内処理のみで送信/保管なし。**将来サーバー送信・解析ログ・アクセス解析を入れる場合はプライバシーポリシー必須**。公開前に「データを送信しない」の記載が実装と一致していることを人間が最終確認 |
| 特商法 | ⚠️ 要対応(有料化時) | 現MVPは無料・無登録。有料プラン/寄付/広告収益化の際は特定商取引法に基づく表記(事業者名・住所・連絡先等)が必要。**事業者情報の記入は人間が行う** |
| 誇大表現 | ✅ 確認済 | LP/SNS草稿に「必ず節約できる」等の保証表現なし。「推定」「目安」を明記 |
| 助言該当性 | ⚠️ 要確認 | 家計・金融の助言ではなく検出結果の表示に留める旨をフッターに記載済。アフィリエイト(解約代行・乗換サービス等)を付ける場合は広告表記(ステマ規制)が必要 |
| 光熱費・保険等 | 参考 | 解約すると不利益がある契約(保険等)は「解約推奨」と表現しない |
