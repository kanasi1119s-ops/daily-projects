# LP草稿・SNS告知文(コピペ用)
## LP
**見出し**: 「使ってないサブスク」、見つけませんか?
**サブ**: 登録なし・データは端末内だけ。契約中のサブスクを入れるだけで、見直し候補がひと目でわかります。
**特長**
1. 月額・年額を自動換算 — 年払い・3か月払いも月額に揃えて合計
2. 利用1回あたりのコストを表示 — 「月1回しか見ていない動画サービス」に気づける
3. 重複カテゴリを検出 — 動画・音楽などの複数契約を整理する目安に
4. 解約した場合の試算 — チェックするだけで節約額の目安を表示
5. データは端末内のみ — アカウント登録不要。CSVで書き出し/読み込み
**料金案(仮説・要検証)**: 基本機能は無料。将来案: 広告なしの有料版(CSV一括管理・リマインド等)は検討段階
**注意書き**: 表示は入力値に基づく目安です。解約・契約変更の判断と実際の料金は各サービスの公式情報でご確認ください。
