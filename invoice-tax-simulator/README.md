# インボイス納税額シミュレーター

個人事業主向けに、消費税の納付額を **本則課税 / 簡易課税 / 2割特例(令和8年分) / 3割特例(令和9〜10年分)** で並べて比較する静的Webツール。入力値はブラウザ内で計算され、サーバー送信・保存はしません。

- コンセプト: 「2割特例が終わった後、どの方式が一番得か」を30秒で試算
- ターゲット: インボイス登録済みの個人事業主・フリーランス
- 収益化仮説(未検証): 広告 / 会計・請求書SaaSへのアフィリエイト / 有料PDFレポート
- 状態: **MVP完成・未公開**(公開判断は人間)

## 起動
```bash
npm start          # http://localhost:5173
npm test           # 単体テスト(node:test、依存なし)
npm run build      # dist/ に静的ファイルを出力
# ブラウザE2E(任意): PORT=5199 npm start のあと
NODE_PATH=$(npm root -g) node test/e2e.mjs   # playwright が必要
```
依存パッケージはありません(Node 20+)。

## 構成
```
index.html        画面
src/calc.js       計算ロジック(純関数・テスト対象)
src/app.js        DOM連携
src/style.css     スタイル(ダークモード対応)
test/             単体テスト / E2E
scripts/          開発サーバー / ビルド
docs/             要件・法務・QA・公開手順・LP・SNS
```

## MVPスコープ
含む: 標準税率10%、4方式の比較、国税/地方消費税の内訳、適用要件の簡易判定、還付表示
含まない: 軽減税率、事業区分の混在(2種類以上)、免税事業者からの仕入れ経過措置、売上返還、中間納付、結果の保存/PDF出力

## 免責
一般的な試算ツールであり税務助言ではありません。3割特例は令和8年度税制改正に基づく内容で、公式の確定情報を必ず確認してください。
