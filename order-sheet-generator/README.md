# フリーランス発注書メーカー

フリーランス新法(特定受託事業者に係る取引の適正化等に関する法律)で求められる取引条件の明示項目を入力し、発注書の雛形を生成する静的Webツール。
入力内容はブラウザ内だけで処理され、サーバーへ送信されません(外部通信・Cookie・解析タグなし)。

## 起動
ビルド不要。`index.html` をブラウザで開く、または `python3 -m http.server` で配信。

## テスト
`node --test`(Node 18+)

## 構成
- `lib.js` 検証・文書生成ロジック(DOM非依存)
- `app.js` / `index.html` / `style.css` UI
- `test/lib.test.js` 単体テスト
- `docs/` QA・法務・公開手順・マーケ素材

## MVPスコープ
含む: 必須項目の入力検証、60日ルールの警告、検査有無・報酬算定方法・現金以外の支払への対応、コピー/印刷。
含まない: 保存・アカウント、PDF直接生成、請求書機能、決済。
