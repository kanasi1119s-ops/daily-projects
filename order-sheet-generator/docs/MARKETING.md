# マーケ素材(誇大表現なし)
## LP草稿
**見出し**: 発注書づくりの「書き漏れ」に気づけるツール
**サブ**: フリーランスへ業務を委託するとき、明示が求められる項目を入力するだけ。雛形を作成できます。
**特長**
- 必要項目をフォームで順に入力(入力漏れはエラー表示)
- 支払期日が納期から60日を超える場合は注意表示
- 検査の有無・報酬の算定方法・現金以外の支払にも対応
- 入力内容はブラウザ内で処理。サーバーに送信しません
- コピーまたは印刷/PDF保存
**料金案(仮説・未検証)**: 基本機能は無料。将来、履歴保存や複数明細などを有料プランとして検証。
**注意書き**: 本ツールは雛形の作成を補助するもので、法的助言ではありません。
