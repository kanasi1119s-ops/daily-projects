# 公開手順書(人間が実行)
本セッションでは本番反映・ドメイン取得は一切行っていません。

1. 法務レビューの★要対応(一次資料照合)を完了する。
2. `npm test && npm run build` を実行し、`dist/` を生成。
3. 無料で公開する場合(費用なし): GitHub Pages / Cloudflare Pages / Netlify 等に `dist/` を配置(静的のみ。環境変数・シークレット不要)。
4. 独自ドメインを使う場合はドメイン取得とDNS設定(要人間の承認・費用発生)。
5. 収益化する場合: 広告タグの追加(プライバシーポリシー更新が必要)、または有料プラン化(Stripe接続・特商法表記は人間が実施)。
6. 公開後の確認: スマホ幅での表示、免責文の表示、リンク切れ。
