# 取適法セルフチェッカー

取引条件(取引の種類・双方の規模・支払条件・行為)を入力すると、取適法(中小受託取引適正化法)上の注意点を洗い出す静的Webツールです。入力は端末内でのみ処理され、送信されません。依存パッケージなし(Node.js 18+)。

> 一般的な情報提供であり法的助言ではありません。数値基準は解説記事に基づく目安で、**公開前に公正取引委員会・中小企業庁の一次資料で照合が必要**です(docs/LEGAL_REVIEW.md)。

## 起動
```
npm start        # http://localhost:5173 (PORT=xxxx で変更)
npm test         # ロジックの単体テスト(17件)
npm run build    # dist/ に静的ファイルを出力
```
ES Modules を使うため `file://` で直接開くと動きません。`npm start` か静的ホスティングを使ってください。

## 構成
- `src/logic.js` 判定ロジック(DOM非依存) / `src/app.js` UI / `index.html` `style.css`
- `test/` 単体テスト / `scripts/` ビルド・開発サーバ / `docs/` QA・法務・公開手順・LP/SNS

## MVPの範囲
含む: 適用判定(資本金・従業員基準)、支払期日60日、支払手段、取引条件の明示、禁止行為チェックリスト。
含まない: 条文引用の自動表示、PDF出力、保存機能、アカウント、決済。
