# 発注明示くん（freelance-order-notice）

フリーランス取引適正化法（特定受託事業者に係る取引の適正化等に関する法律）の「取引条件の明示」項目を漏れなく入力し、支払期日（受領日から60日／再委託は30日）を自動チェックして明示書の雛形を作るブラウザ完結ツール。

- スタック: React + TypeScript + Vite（バックエンドなし。入力はブラウザ内のみで処理、保存・送信なし）
- 起動: `npm install && npm run dev`
- テスト: `npm test` / ビルド: `npm run build`
- 構成: `src/lib/notice.ts`（判定ロジック・テスト付き）、`src/App.tsx`（UI）、`docs/`（公開手順・LP・法務・QA）

## MVPスコープ
含む: 必須明示項目の入力と漏れチェック、支払期日上限の算出と超過警告、プレビュー、コピー、印刷/PDF保存
含まない: ログイン、保存、メール送信、電子署名、決済

> 本ツールは雛形作成ツールで法的助言ではありません。
