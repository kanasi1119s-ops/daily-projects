# LP草稿
**見出し**: 発注書の「抜け」、30秒でチェック。
**サブ**: フリーランスへの発注時に必要な取引条件の明示項目を入力するだけ。支払期日の上限もその場で確認できます。
**特長**
- 明示すべき項目を順に入力、未入力は即指摘
- 受領日から60日（再委託は30日）の支払期日上限を自動計算
- 入力はブラウザ内で処理。サーバーに送信しません
- コピー・印刷/PDF保存に対応
**料金案（仮説・要検証）**: 基本機能は無料／将来案として、履歴保存・テンプレ管理を月額数百円で提供することを検討
**注意**: 本ツールは雛形作成の補助であり、法的助言ではありません。
