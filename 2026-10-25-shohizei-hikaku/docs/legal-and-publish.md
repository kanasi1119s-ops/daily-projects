# 法務チェックと公開手順(人間向け)

## Legal-Reviewer チェック結果
- [x] 第三者コンテンツ: 画像・外部文章・外部データ不使用(自作のみ)
- [x] スクレイピング: なし
- [x] 個人情報: 取得・送信・保存なし(外部通信なし、Cookie/解析タグなし)
- [x] 収益保証表現: なし。節税効果の断定を避け「概算・参考」と明記
- [ ] ★要確認: 税額計算の説明は「税務相談」に該当しないよう免責を記載済み。公開前に税理士等の確認を推奨(税理士法上、個別具体的な税務相談の形にしないこと)
- [ ] ★要確認: 制度値(2割/3割特例の期間・割合、届出期限)を国税庁の最新ページで照合
- [ ] ★広告・課金を付ける場合: 特定商取引法表記、プライバシーポリシー(解析・広告タグ利用時)が必要。事業者情報は人間が記入

## 公開手順(本番反映は人間が実施)
1. `npm test && npm run build`
2. `dist/` を静的ホスティング(Cloudflare Pages / Netlify / GitHub Pages 等)へデプロイ
3. 独自ドメインを使う場合はドメイン取得・DNS設定(人間が実施)
4. 公開前に上記★項目を確認
