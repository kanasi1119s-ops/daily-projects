# 消費税 納税方式かんたん比較

個人事業主向けに、**原則課税 / 簡易課税 / 2割特例 / 3割特例**の消費税納付額(概算)を並べて比較する静的Webツールです。計算はすべてブラウザ内で行い、入力値は送信・保存しません。

## 起動
```
npm test        # ロジックのテスト (Node 20+, 依存なし)
npm start       # http://localhost:5173
npm run build   # dist/ に静的ファイルを出力
```
E2E確認用スクリプトは `scripts/e2e*.cjs` (Playwright が必要、任意)。

## 構成
- `src/calc.js` 計算ロジック(税率・特例割合は定数。改正時はここのみ修正)
- `src/app.js` UI / `index.html` / `style.css`
- `test/` 単体テスト / `docs/` 公開手順・法務・LP/SNS草稿

## 既知の制約
- 事業区分は1つのみ(複数業種の按分・特例計算は未対応)
- 中間納付、非課税売上、貸倒れ、仕入税額控除の経過措置(80%控除等)は未考慮
- 3割特例(令和9・10年分)は二次情報で記述が分かれるため、国税庁の確定情報での確認が必要
- 簡易課税の適用可否(基準期間・届出)はユーザー入力のチェックに依存
