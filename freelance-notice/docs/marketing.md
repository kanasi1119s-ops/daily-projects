# LP草稿・SNS告知文 (Sales-Writer)

## LP
**見出し**: フリーランスへの発注、取引条件の明示はこれ1枚で。
**サブ**: 必要項目を入力するだけ。入力内容はブラウザの外に出ません。
**特長**
- 明示が必要な項目(業務内容・報酬額・支払期日・納品日/場所・検査・支払方法)を抜け漏れなく入力
- 支払期日が納品日から60日を超えると注意表示
- テキストのコピー/保存/印刷(PDF化)に対応
- 登録不要・サーバー保存なし
**料金案(仮説)**: 基本無料 / 将来案: 履歴保存・複数テンプレートの有料プラン(要検証)
**注意書き**: 本ツールは法的助言ではありません。最終確認は公的資料または専門家にて。

## SNS (3案)
1. 発注側の皆さん、フリーランスへの取引条件の明示、書面やメールで残せていますか? 必要項目を入力するだけで明示書テキストを作れる無料ツールを作りました。入力はブラウザ内のみ。※法的助言ではありません
2. 「業務内容・報酬・支払期日…何を書けばいい?」を減らしたくて、取引条件明示書ジェネレーターを作りました。支払期日が60日超だと注意表示も。登録不要です。
3. 【個人開発】フリーランス新法の取引条件明示、入力→コピー/印刷だけ。データはサーバーに送りません。フィードバック歓迎です。
