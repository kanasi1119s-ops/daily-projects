# フリーランス取引条件明示書ジェネレーター

フリーランス新法(特定受託事業者に係る取引の適正化等に関する法律)第3条の明示事項を入力し、明示書テキスト生成+支払期日60日ルールの警告を行う静的Webツール。入力はブラウザ内のみで処理(サーバー送信なし)。

## 起動
- `index.html` をブラウザで開く(ビルド不要・依存なし)
- テスト: `npm test` (Node 18+)

## 構成
- `src/core.js` 検証・文書生成(純粋関数) / `src/app.js` UI / `test/` 単体テスト
- `docs/` 公開手順・法務チェック・LP・SNS / `reports/` 日次レポート

## 制約
法的助言ではありません。明示事項の網羅性は公開前に専門家確認が必要です(docs/legal-check.md)。
