# フリーランス取引条件 明示書ジェネレーター

フリーランス・事業者間取引適正化等法(いわゆるフリーランス新法)で発注者に求められる取引条件の明示事項を入力し、明示書テキストを生成する静的Webツール。入力内容はブラウザ内でのみ処理され、外部送信・保存は行いません。

## 起動
```
npm install
npm run dev      # 開発サーバー
npm test         # ユニットテスト(vitest)
npm run build    # 型チェック + 本番ビルド → dist/
```

## 構成
- `src/notice.ts` 検証(必須項目・日付・60日ルール警告)と文書生成の純関数
- `src/main.ts` フォームUI(コピー/テキスト保存/印刷)
- `tests/` ユニットテスト
- `docs/` 日次レポート・LP草稿・SNS文・公開手順書・法務チェック

## 注意
法律の専門家による助言ではありません。項目は公的資料での最終確認が必要です(docs/legal-check.md 参照)。
