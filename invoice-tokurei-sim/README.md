# インボイス特例シミュレーター

2割特例（令和8年9月30日を含む課税期間で終了）、3割特例（個人・令和9〜10年分）、簡易課税、本則課税の**納付税額を並べて試算**する静的Webツールです。免税事業者からの仕入に係る控除割合（80%→70%→50%→30%→0%）も反映します。

> 試算専用。税務・法律上の助言ではありません。入力値はブラウザ内で計算され、外部送信・保存はしません。

## 起動手順
```bash
cd invoice-tokurei-sim
npm install
npm run dev      # 開発サーバ
npm test         # 計算ロジックの単体テスト
npm run build    # dist/ に静的ファイルを出力
```

## 構成
- `src/calc.ts` 計算ロジック（純関数・テスト対象）
- `src/main.ts` UI（DOM操作。`textContent`のみ使用しXSS面を排除）
- `tests/calc.test.ts` vitest
- `docs/` 法務チェック・公開手順書・LP/SNS草稿・QA記録

## 既知の制約（MVP）
- 事業区分は単一区分のみ（複数事業の按分は未対応）
- 端数処理は合計額ベース。貸倒れ・課税売上割合・固定資産の調整は非対応
- 免税事業者からの仕入の年間上限額（令和8年度改正）は未反映
- 3割特例・70%控除は令和8年度税制改正に基づく。公布法令での最終確認が必要
