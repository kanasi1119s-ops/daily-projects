# インボイス 消費税 方式かんたん比較

個人事業主向け。令和8〜10年分の消費税納付額を **原則課税 / 簡易課税 / 2割特例 / 3割特例** で並べて概算するブラウザ完結の静的Webツール。入力値は外部送信・保存しません。

## 起動
```bash
npm install
npm run dev        # 開発サーバ
npm test           # 単体テスト(vitest)
npm run build      # 型チェック + 本番ビルド → dist/
# E2E(Chromium必要): npm run preview -- --port 4173 を起動した状態で node tests/e2e.mjs
```

## 構成
- `src/calc.ts` 計算ロジック(整数演算・純関数) / `src/main.ts` UI / `tests/` テスト
- `docs/` 法務チェック・公開手順・QA記録・LP/SNS草稿

## 制約（MVP）
標準税率10%のみ・税込入力。軽減税率8%、按分、2割特例の細かな端数処理・届出特例は未対応。一般的な情報提供であり税務相談ではありません。
根拠: 令和8年度税制改正（2割特例は令和8年9月30日を含む課税期間まで／個人事業者は令和9・10年分に3割特例／免税事業者等からの仕入控除は70%→50%）。**公開前に国税庁の最新情報で再確認**すること。
