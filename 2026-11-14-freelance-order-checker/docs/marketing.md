# LP草稿・SNS告知文（Sales-Writer）
## LP
**見出し**: フリーランスへの発注、取引条件の書き漏れはありませんか？
**サブ**: 必須の明示項目と支払期日を3分でセルフチェック。発注書テキストもそのまま作成。入力内容は送信されません。
**機能**
- 対象になるかの目安判定
- 明示項目の漏れ・曖昧な記載の検出
- 支払期日が受領日から60日以内かの確認
- 禁止行為セルフチェック
- 発注書テキストのコピー／印刷
**料金案（仮説）**: 基本機能は無料。将来、テンプレ保存・複数案件管理を有料プラン候補として検証。
**注意書き**: 一般的な情報提供であり法的助言ではありません。個別の判断は公正取引委員会・専門家へ。

3. 発注書の書き漏れ防止に。報酬額・納期・支払期日など必要項目をチェックリスト化しました。無料・登録不要。（URL）
