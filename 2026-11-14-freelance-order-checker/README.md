# 発注明示チェッカー

フリーランスへ業務委託する際の「取引条件の明示」漏れ（フリーランス新法 第3条）と、支払期日の60日ルール（第4条）をブラウザ内でチェックし、発注書テキストを生成する静的Webツール。**入力内容は外部送信されません。**

## 起動
```bash
npm install
npm run dev      # 開発サーバ
npm test         # ユニットテスト(vitest)
npm run build    # 本番ビルド → dist/
```

## 構成
- `src/lib/check.ts` 判定ロジック（純関数）／`check.test.ts` テスト
- `src/App.tsx` UI（対象判定・入力・結果・禁止行為チェック・発注書生成）
- `docs/` 法務チェック・公開手順・LP・SNS・QA・日次レポート

## 免責
一般的な情報提供であり法的助言ではありません。
