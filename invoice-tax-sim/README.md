# インボイス消費税シミュレーター

フリーランス・個人事業主向け。年間の課税売上と経費から、**本則課税・簡易課税・2割特例**の納税額(概算)を比較し、最も低い方式と月々の積立目安を表示します。依存パッケージなし・ブラウザ内計算のみ(入力値は送信されません)。

## 起動
```
npm test        # ユニットテスト(Node 22+)
npm run build   # dist/ に静的ファイルを出力
npm start       # http://localhost:8080 (プロジェクト直下を配信)
```

## 構成
- `src/calc.js` 計算ロジック(純粋関数、税率・控除率は引数で上書き可)
- `src/app.js` / `index.html` / `src/style.css` UI
- `docs/` 法務チェック・公開手順・LP草稿・SNS文面

## 既知の制約
- 概算のみ(端数処理は簡略化、地方消費税は10%に内包)
- 2割特例・簡易課税の適用要件(届出期限・基準期間)は判定せず、前提としてユーザーが選択
- 還付申告・課税期間の特例・複数税率には未対応
- 経過措置の控除率(2026-10-01以降50%)は実装時点の理解。**公開前に国税庁情報で要確認**
