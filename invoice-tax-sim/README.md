# インボイス登録 納税額シミュレーター

免税のまま／本則課税／簡易課税／2割特例の概算納税額を比較する静的Webツール(依存なし・クライアント完結)。

## 起動
- `index.html` をブラウザで開く(または `npx serve .`)
- テスト: `npm test`

## 構成
- `src/calc.js` 計算ロジック(UMD) / `index.html` UI / `test/` テスト
- `docs/` 公開手順書・法務チェック・LP/SNS草稿

## 制約
標準税率10%のみ。軽減税率・非課税・課税売上割合・所得税は未対応。概算であり税務助言ではありません。
