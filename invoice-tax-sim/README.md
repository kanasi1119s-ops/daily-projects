# 消費税 課税方式かんたん比較

本則課税・簡易課税・2割特例の概算納税額を比較する静的Webツール。ビルド不要・外部依存なし。入力はブラウザ内でのみ計算され、送信されません。

## 起動
- `index.html` をブラウザで開く(または `python3 -m http.server` で配信)
- テスト: `node test.js`

## 構成
- `calc.js` 計算ロジック(UMD。ブラウザ/Node両対応)
- `index.html` UI
- `test.js` ロジックのテスト
- `docs/` 公開手順書・法務チェック・QA記録・マーケ素材

## 制約
税率10%のみ。軽減税率、非適格仕入の経過措置、中間納付は未対応。概算であり税務助言ではありません。
