# 消費税 納付額シミュレーター（インボイス対応）

本則課税・簡易課税・2割特例の納付税額（概算）を同条件で並べて比較する、ブラウザ完結の静的Webツール。
入力値は外部送信されません（サーバー・DB・トラッキング無し）。

## 起動
```bash
npm install
npm run dev      # 開発サーバー
npm test         # 単体テスト (vitest)
npm run build    # 型チェック + 本番ビルド → dist/
```

## 構成
- `src/calc.ts` 計算ロジック（純粋関数）
- `src/main.ts` / `index.html` / `src/style.css` UI
- `tests/calc.test.ts` テスト
- `docs/` 法務チェック・公開手順・LP/SNS草稿

## MVPスコープ
含む: 10%/8%売上・仕入、免税事業者等からの仕入の経過措置、事業区分1〜6、各方式の適用可否判定
含まない: 複数事業区分の按分(簡易課税)、特例計算(75%/80%)、中間納付・端数の国税/地方税分離、帳簿出力
※ 税務助言ではなく概算。最終判断は税理士・税務署へ。
