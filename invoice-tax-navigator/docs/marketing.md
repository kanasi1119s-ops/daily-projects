# LP草稿 / SNS告知文
## LP
**見出し**: 2027年、あなたの消費税はどの方式が軽い? 3方式を30秒で比較
**サブ**: 原則課税・簡易課税・3割特例を、売上と仕入を入れるだけで比較。入力内容は送信も保存もされません。
**特徴**
- 3割特例(2027・2028年分・個人事業主向け)を含む3方式を同時比較
- 簡易課税の届出期限(2026年12月31日)までの残り日数を表示
- 会員登録不要・無料・端末内で計算
**使い方**: 1.売上・仕入を入力 2.事業区分を選ぶ 3.一覧で比較
**注意書き**: 目安であり税務上の助言ではありません。最終判断は国税庁の情報または税理士へ。前提条件(税率10%のみ、設備投資は考慮せず等)あり。
**料金案(仮説)**: 基本機能は無料。将来案として、年間レポートPDF出力を有料機能にする検討(未決定)。
## SNS
1. 2割特例が終わり、2027年からは3割特例(個人事業主・2年間)になります。原則課税・簡易課税と並べて比べられる無料ツールを作りました。入力は端末内で計算されます。※目安です
2. 簡易課税に切り替えるなら、2027年分は2026年12月31日までに届出が必要です。自分の場合はどの方式が軽いか、まず試算を。
3. 「仕入が売上の何%を超えたら原則課税が有利?」事業区分ごとの分岐点がわかります。個別の税務判断は税理士・国税庁でご確認を。
Self-check: 「必ず得」「節税保証」等の断定なし。目安・前提を明記。OK
