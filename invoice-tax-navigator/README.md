# インボイス課税方式ナビ 2027

2027年(令和9年)分の消費税について、**原則課税 / 簡易課税 / 3割特例**の納付税額を比較する静的Webツール。入力は端末内で計算し、送信・保存しません。

- ターゲット: 免税事業者からインボイス登録した個人事業主・小規模事業者
- 収益化仮説(未検証): 記事/アフィリエイト(会計ソフト・税理士紹介)、広告。※公開前に人間が要判断
- MVP範囲: 税率10%・単一事業区分・適格請求書前提。非対応: 軽減税率、複数事業区分、設備投資、免税事業者からの仕入経過措置

## 起動
```
npm install
npm run dev      # 開発サーバ
npm test         # 計算ロジックのテスト
npm run build    # dist/ に静的ファイル生成
```

## 構成
- `src/calc.ts` 計算ロジック(純関数)
- `src/main.ts` UI / `src/style.css`
- `tests/` vitest
- `docs/` 企画・QA・法務・公開手順・LP/SNS草稿

制度根拠は国税庁の公表資料を必ず確認してください(`docs/legal-review.md`)。
